# TV Launcher

[English](README.md) · Русский

TV Launcher (название будет определено позже) — это лаунчер для Android, предназначенный для больших экранов, например телевизоров. Его можно использовать вместо стандартного лаунчера Leanback или Google TV на различных устройствах Android TV, таких как Nvidia Shield или Chromecast with Google TV.

В настоящее время приложение находится на ранней стадии разработки.

## Планируемые функции

- Настраиваемая панель инструментов

  Панель инструментов отображается в верхней части экрана и содержит различные элементы, которые пользователь может скрывать и перемещать. Планируемые компоненты:

    - Часы
    - Кнопка настроек
    - Переключатель источников ТВ-сигнала

- Список избранных приложений

  Список приложений, добавленных пользователем в избранное. Их можно показывать или скрывать на главном экране, а также менять их порядок.

- Каналы

  Каналы, предоставляемые приложениями, и информация о том, что посмотреть далее.

- Все приложения

  Сетка со всеми установленными приложениями. Также можно отображать мобильные приложения.

### Нереализуемые функции

Некоторые функции невозможно реализовать из-за ограничений платформы. Недоступны следующие функции:

- Обои

  Android TV не позволяет приложениям устанавливать обои, поскольку в системе отсутствует реализация действий
  [WallpaperManager](https://developer.android.com/reference/android/app/WallpaperManager.html).
